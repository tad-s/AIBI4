RULES 除外ルールはどこ？

除外専用テーブルはありません。ルールはファイル＋コードにあり、構築時に適用。通過した行だけが PoCテーブルに入ります（宴/ＦＤは物理削除済み）。

  • ランチ定食ファイル etc/池袋東口店_定食メニュー.txt
  • 分析対象外（¥0系等）ファイル etc/分析対象外メニュー.csv
  • コース・放題コード _COURSE_KW（base_table.py）
  • 宴会「宴」・飲み放題「ＦＤ」コード _EXCLUDE_ITEM_KW＋テーブルからDELETE済
  • システム項目分類が 除外（item_category_master ＋ POC_OVERRIDES）
  • 時間帯 / 期間 / 単独客 / M行コードの条件（base_table.py）

KEY 重要な区別 — 決定論 vs LLM

⚖️

決定論 PoCの8指標は固定コードで集計・作図（LLM不使用・再現性あり）。  LLM PoCチャットだけが、同じPoCデータに対してLLMがコードを生成→サーバーでexec→作図、という別経路です。

MORE 補足 — 同じ df を共有
